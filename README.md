# Customer Churn Analysis and Prediction

## Data Science Tool Mastery Project

### Project Overview

This project demonstrates an end-to-end data science workflow for analyzing customer churn and developing predictive machine learning models.

Using the IBM Telco Customer Churn dataset, the project explores customer characteristics, subscription services, billing information, and churn behavior.

### Objectives

- Demonstrate proficiency with industry-standard Python data science libraries.
- Perform dataset exploration and statistical analysis.
- Clean and preprocess customer data.
- Identify customer churn patterns through exploratory data analysis.
- Develop and compare machine learning classification models.
- Evaluate model performance using standard classification metrics.

### Dataset

**Dataset:** IBM Telco Customer Churn

**Source:** [Kaggle – Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn)

The original dataset contains 7,043 customer records and 21 attributes, including demographic information, contract types, internet services, monthly charges, and churn status.

### Project Workflow

1. Data Collection and Loading
2. Dataset Exploration and Statistical Analysis
3. Data Cleaning and Preprocessing
4. Exploratory Data Analysis
5. Data Visualization
6. Machine Learning Model Development
7. Model Evaluation and Comparison

### Machine Learning Models

Two classification models were implemented:

**Logistic Regression:** A supervised learning algorithm used for binary classification.

**Random Forest:** An ensemble learning algorithm that combines multiple decision trees to improve predictive performance.

### Model Evaluation

Model performance is assessed using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

The trained models are compared to understand their relative performance in identifying customer churn.

### Visualizations

The project includes visualizations covering customer churn distribution, contract types, customer tenure, monthly charges, payment methods, internet services, and model performance.

### Conclusion

This project demonstrates practical proficiency in data analysis, visualization, preprocessing, and machine learning using Python and industry-standard libraries.

It provides experience with an end-to-end data science workflow and serves as a portfolio project for data science and data analytics roles.
